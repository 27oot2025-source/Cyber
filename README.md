# ГОССЕТЬ-84 // ТЕРМИНАЛ ГОСУДАРСТВЕННОЙ СЕТИ

Советский ретро-киберпанк в браузере. Год — всегда 1984-й, неон — всегда одобренный,
дроид-дежурный КТ-1 — всегда на связи.

## Запуск

Любой статический сервер, например:

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

Сборка не требуется: чистые HTML + CSS + JS, без зависимостей.

## Что внутри

- **Загрузочная последовательность БИОС** — печать строк, пропуск любой клавишей
- **8 вкладок** (клавиши 1–8): ГЛАВНАЯ, ЛЕНТА, ДОСЬЕ, ВОЛНЫ, АРКАДА, ТЕРМИНАЛ, МАГАЗИН, СВЯЗЬ
- **Canvas-горизонт** — несущаяся неоновая сетка, полосатое солнце, мерцающие звёзды
- **Синтезатор Web Audio** — 4 чиптюн-трека в реальном времени + все звуки интерфейса
- **Живой терминал** — команды `помощь`, `взлом`, `досье`, `тема`, `радио` и другие
- **Аркада** — «Змейка-84» с рекордами и тест рефлексов
- **Картотека, магазин с корзиной, телеграммы, опрос недели** — всё хранится в `localStorage`
- **ЭЛТ-эффекты**: сканлайны, мерцание, RGB-расщепление, 4 цветовые схемы, ТУРБО-режим
  (код: ↑ ↑ ↓ ↓ ← → ← → B A)

Осторожно, товарищ: сеть всё записывает.
